# 🖥️ Simulador de Sistema Operacional 

Este projeto é um simulador de um Sistema Operacional, desenvolvido para a disciplina de **Sistemas Operacionais** para o curso de **Licenciatura em Computação** da **UFRPE**. O objetivo é simular o funcionamento lógico de diretórios em árvore, além da camada física de alocação de blocos em um disco rígido virtual.
